# Design reference

The grouped native session menu, elapsed-time presentation, and separation of
options and appearance controls were informed by Codex Status Bar:
https://github.com/yuriipalam/codex-status-bar

Codex Menu retains its own session tracking, per-session native buttons, progress
display, lamp rendering and navigation. No upstream binary, icon assets or
third-party runtime dependencies are included. The upstream license is reproduced
here to preserve attribution for the reference implementation.
